## 编辑入口

- `macro_sources.txt`：104 个既有来源账户。为兼容迁移保留完整采集目录，包括宏观、新闻、研究、地缘叙事、交易者及候选；不是重新分类后的 104 位宏观作者。
- `trader_authors.txt`：8 个允许提取交易者原观点的作者，全部与上述来源目录重叠。

每行一个用户名，可以保留或省略开头的 `@`。允许空行和 `#` 注释；删除或注释一行表示在该产品中停用。同一账户仍在另一份名单时，仍属于另一产品。

计划适配规则：去空白、去掉一个开头的 `@`、按 `[A-Za-z0-9_]{1,15}` 校验、不区分大小写去重并提示重复；非法行拒绝整个新版本。当前仓库只保存数据，上述规则尚未接入运行管线。

两份 TXT 是名单成员的唯一人工编辑入口。后续 JSON/YAML 只能由适配器生成，不能独立修改。

## 后续接入边界

- 每轮固定同一完整 commit，保存实际采用的文本、归一化名单及哈希；本轮不切换版本。
- 下载或校验失败时，整套沿用上次已验版本并明确陈旧和最后验证时间；没有已验版本时暂停，不能回退到未发布工作区。
- 保持既有常驻/按需和费用边界；新增账户默认按需，加入名单不构成新增采集费用或扩大预算的授权。
- Grok 是否能实际读取本仓库并采用指定 commit，必须实测。名单一致不等于两端实际覆盖一致。
- 非 X 来源 URL 文本暂未建立；既有非 X 域名目录不代表已抓取正文，也不自动满足网站公开产物合同。

本仓库不包含应用代码、原始日志、凭据、账户或持仓数据。没有在此设置 Actions 工作流、GitHub Pages 或 Vercel 部署，也没有通过本次发布改变生产代码、定时任务或发送行为。
